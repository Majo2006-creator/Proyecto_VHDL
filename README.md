# Diseño, Modelado y Verificación de Sistemas Digitales usando VHDL

## Descripción

Proyecto desarrollado para la implementación y verificación de circuitos digitales utilizando el lenguaje VHDL.

## Circuitos implementados

- Compuerta AND de dos entradas
- Sumador de 2 bits
- Multiplexor 2:1
- Decodificador 2 a 4
- Comparador de 2 bits

## Verificación

Cada circuito cuenta con su respectivo testbench, utilizando:

- Generación de estímulos
- `assert`
- `wait for`
- Simulación funcional
